# Tombra Mohammed Campaign Website

Modern, mobile-first campaign website for Tombra Jennifer Mohammed, YPP senatorial candidate for Bayelsa West Senatorial District.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Share online

Use GitHub Pages or Vercel for a public link. See `DEPLOY.md` for the deployment steps.

## Notes

- Placeholder images and contact details are included for version one.
- Forms are front-end only. TODO comments mark backend integration points.
- Copy avoids unverified biography, awards, projects, education, family details, or achievements.
